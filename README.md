# Monsterfield

A premium, cosy creature-collecting idle game built around an original world of 151 discoverable species.

## Status
Initial repository foundation. React + TypeScript + Vite.

## Run locally
```bash
npm install
npm run dev
```

The first playable release includes idle gathering, offline earnings, discovery encounters, creature collection, a field guide, sanctuary upgrades and local save data. Creature glyphs are temporary placeholders for original illustration assets.
